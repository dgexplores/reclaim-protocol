# Problem Statement — ReClaim

## Title: No Trustless Proof of Real-World Recycling Exists

### Category
Blockchain / Web3 / DePIN / Sustainability / Oracle Problem

### The Unsolved Problem

Despite blockchain's promise to verify off-chain truth, **physical waste remains unverifiable on-chain.**

1. **Recycling is invisible:** A user claims "I recycled 10 PET bottles" — no decentralized way to prove it. Municipal systems use centralized databases easily falsified.
2. **Incentive misalignment:** Recyclers get near-zero reward; landfilling is cheaper. World Bank: 2.01B tonnes waste/year, only 13.5% recycled globally.
3. **Greenwashing at scale:** Brands report ESG metrics with self-attested data. No audit trail. EU Green Claims Directive (2024) now mandates verifiable proof — market gap.
4. **Oracle Problem for Trash:** Chainlink/UMA solve price feeds, but no oracle solves *image + GPS + material proof* for waste. Existing oracles are price-centric, not physical-action-centric.

### Why Existing Solutions Fail

| Solution | Failure |
|----------|---------|
| Centralized apps (RecycleBank, TrashCoin Web2) | Single point of failure, no token liquidity, no composability |
| Manual audits | Expensive, slow, corruptible |
| Carbon credit markets | Only for large projects, not household-level |
| NFT "eco" projects | No real-world verification, just art |

### Who Suffers

- **Citizens:** No reward for pro-environmental behavior
- **Cities:** Can't incentivize diversion from landfill, pay $55/ton landfill fees
- **Brands / DAOs:** Can't verifiably reward community for IRL impact
- **Web3:** Fails to prove it can solve *physical* coordination, not just financial

### What a Winning Solution Must Do

- Verify physical material via phone alone (no hardware)
- Mint on-chain receipt with anti-gaming guarantees
- Reward proportionally to environmental value
- Be decentralized (no single auditor), cheap (L2), and composable (tokens usable in DeFi/governance)

> ReClaim solves this with AI + IPFS + smart contracts + randomized auditor staking.
